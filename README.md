# Mone Pore - মনে পড়ে

![Go](https://img.shields.io/badge/go-%2300ADD8.svg?style=for-the-badge&logo=go&logoColor=white)
[![LICENSE: MIT](https://img.shields.io/badge/LICENSE-MIT-green?style=for-the-badge)](LICENSE)

A lightweight, offline-first journaling app, focused on privacy, simplicity, and long-term memory keeping.

_**More Pore**_ lets you jot down moments from any point in your life, be it today, or years ago. Every memory has its own date, separate from when you decide to write it down, helping you build your own little box of memories.

## Status

Early development.

## Stack

- Go
- SQLite
- HTML templates
- HTMX

## Development

```bash
go run .
```
